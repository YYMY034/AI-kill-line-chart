# AI 大模型性能-价格斩杀线 2026

一个交互式数据可视化网页应用，用于对比 **2026 年全球主流 AI 大语言模型（LLM）** 的 **智能水平** 与 **使用成本**，帮助用户直观判断哪些模型在“性能 vs 价格”曲线上具备优势（即“斩杀线”——性价比超越同级别竞品的分界线）。

项目以单个 HTML 文件为核心，内置 **100+ 个 AI 模型数据**，支持在线实时抓取最新数据，无需后端服务器，双击 `.bat` 即可使用。

## 🚀 快速使用

1. **双击** `打开AI斩杀线图表.bat`
2. 系统默认浏览器自动打开图表页面
3. 页面加载后先显示内置数据（秒开），随后后台自动抓取最新数据
4. 也可以将 `.html` 文件直接拖入任意浏览器打开

> **注意**：在线数据抓取依赖 CORS 代理，部分网络环境下可能抓取失败，此时会自动回退到缓存或内置数据，不影响使用。

## 📊 图表功能详解

### 核心图表

图表类型为 **散点图（Scatter Plot）**，由 [Plotly.js](https://plotly.com/javascript/) 驱动渲染。

- **每个圆点** = 一个 AI 模型
- **圆点大小** = 输出速度（tokens/s，越大越快）
- **圆点颜色** = 按厂商区分（Anthropic=橙色、OpenAI=绿色、Google=蓝色等）
- **X 轴** = 默认「每任务成本 ($)」，可切换为输入/输出价格、速度、智能指数、性价比
- **Y 轴** = 默认「智能指数 (IQ)」，可切换为 AGI 相对水平(%)、速度、性价比
- **对数 X 轴**：默认开启，便于在跨数量级的价格区间中对比

### 参考线与前沿

| 功能 | 说明 |
|------|------|
| **AGI 参考线** | 5 条水平虚线，标注 IQ 20/30/40/50/60 分别对应 AGI 0%/50%/100%/150%/200%，其中 IQ 40 = 人类专家水平 |
| **帕累托前沿** | 白色虚线，连接每个价格点上“性能最高”的模型，形成性价比前沿 |
| **最低 IQ 过滤** | 滑块控制，过滤掉低于指定智能指数的模型，减少视觉噪音 |

### 交互操作

| 操作 | 效果 |
|------|------|
| **鼠标悬停** | 显示模型详情浮窗（厂商、IQ、AGI水平、成本、输入/输出价格、速度、发布日期、推理能力、性价比） |
| **鼠标滚轮** | 以鼠标位置为中心缩放（非 Plotly 默认的图表中心缩放） |
| **双击图表** | 重置缩放到自适应范围 |
| **拖动** | 平移视图 |
| **左上角 ⛶ 按钮** | 全屏切换（ESC 退出） |
| **右上角工具栏** | 下载 PNG（1920x1080, 2x 高清）、框选缩放、平移等 |
| **厂商 Chip** | 点击切换显示/隐藏某厂商的全部模型 |

### 搜索与定位

页面顶部的搜索框支持按模型名称、厂商名（中英文）搜索：

1. 输入关键词（如 `Claude`、`百度`、`longcat`），实时显示匹配列表
2. 点击搜索结果或按 Enter，图表自动完成定位并播放**粒子十字光效**动画

### 底部排行榜

| 卡片 | 排序依据 |
|------|----------|
| 💰 最佳性价比 Top 10 | 性价比 (IQ/$) 降序 |
| 🏆 性能最强 Top 10 | 智能指数 (IQ) 降序 |
| ⚡ 速度最快 Top 10 | 输出速度 降序 |

## 🏗️ 技术架构

```
ai_kill_line_2026.html  （单文件，约 1894 行）
├── <head>
│   ├── Plotly.js CDN 引用
│   └── <style> 全部 CSS（暗色主题，约 210 行）
├── <body>
│   ├── 页面结构（标题栏、控制栏、厂商筛选、图表容器、信息面板、页脚）
│   └── <script> 全部 JavaScript（约 1600 行）
└── 核心逻辑模块
    ├── 数据层（内置数据 + 缓存 + 在线抓取）
    ├── 图表渲染层（updateChart + 布局 + 标签防重叠）
    ├── 搜索定位层（locateModel + doGlow 粒子动画）
    ├── 交互增强层（滚轮缩放、全屏、汉化工具栏）
    └── 信息面板层（排行榜）
```

### 数据层（三级数据源）

- **内置数据**：硬编码 100+ 模型 JSON
- **localStorage 缓存**：通过 `CACHE_KEY = 'ai_kill_line_data_cache_v10'` 版本号管理
- **在线抓取**：Artificial Analysis 排行榜，多 CORS 代理轮询 + 分层 HTML 解析（正则 → Markdown → 管道符）

### 关键设计

- 三级数据源 + 缓存版本控制，可强制用户刷新缓存
- 标签防重叠算法：8x8 网格碰撞检测，为每个标签选择冲突最小的位置
- 搜索定位自动做厂商激活、IQ 过滤调整、坐标轴兼容切换
- 粒子光效动画（2.5 秒）：十字线 + 脉冲光点 + 灰色粒子

# AI 大模型性能-价格斩杀线 2026

## 📋 项目概述

这是一个**交互式数据可视化网页应用**，用于对比 2026 年全球主流 AI 大语言模型（LLM）的**智能水平**与**使用成本**，帮助用户直观判断哪些模型在"性能 vs 价格"曲线上具有优势（即"斩杀线"——性价比超越同级别竞品的分界线）。

项目以一个单 HTML 文件为核心，内置 **100+ 个 AI 模型数据**，支持在线实时抓取最新数据，无需后端服务器，双击 `.bat` 即可使用。

## 🚀 快速使用

1. **双击** `打开AI斩杀线图表.bat`
2. 系统默认浏览器自动打开图表页面
3. 页面加载后先显示内置数据（秒开），然后后台自动抓取最新数据
4. 也可以将 `.html` 文件直接拖入任意浏览器打开

> **注意**：在线数据抓取依赖 CORS 代理，部分网络环境下可能抓取失败，此时会自动回退到缓存或内置数据，不影响使用。

## 📊 图表功能详解

### 核心图表

图表类型为**散点图（Scatter Plot）**，由 [Plotly.js](https://plotly.com/javascript/) 驱动渲染。

- **每个圆点** = 一个 AI 模型
- **圆点大小** = 输出速度（tokens/s，越大越快）
- **圆点颜色** = 按厂商区分（如 Anthropic=橙色、OpenAI=绿色、Google=蓝色等）
- **X 轴** = 默认「每任务成本 ($)」，可切换为输入/输出价格、速度、智能指数、性价比
- **Y 轴** = 默认「智能指数 (IQ)」，可切换为 AGI 相对水平(%)、速度、性价比
- **对数 X 轴**：默认开启，便于在跨数量级的价格区间中对比

### 参考线与前沿

| 功能 | 说明 |
|------|------|
| **AGI 参考线** | 5 条水平虚线，标注 IQ 20/30/40/50/60 分别对应 AGI 0%/50%/100%/150%/200%，其中 IQ 40 = 人类专家水平 |
| **帕累托前沿** | 白色虚线，连接在每个价格点上"性能最高"的模型，形成性价比前沿。位于前沿上的模型 = 同价位最优选择 |
| **最低 IQ 过滤** | 滑块控制，过滤掉低于指定智能指数的模型，减少视觉噪音 |

### 交互操作

| 操作 | 效果 |
|------|------|
| **鼠标悬停** | 显示模型详情浮窗（厂商、IQ、AGI水平、成本、输入/输出价格、速度、发布日期、推理能力、性价比） |
| **鼠标滚轮** | 以鼠标位置为中心缩放（非 Plotly 默认的图表中心缩放） |
| **双击图表** | 重置缩放到自适应范围 |
| **拖动** | 平移视图 |
| **左上角 ⛶ 按钮** | 全屏切换（ESC 退出） |
| **右上角工具栏** | 下载 PNG（1920x1080, 2x 高清）、框选缩放、平移等 |
| **厂商 Chip** | 点击切换显示/隐藏某厂商的全部模型 |

### 搜索与定位

页面顶部的搜索框支持按模型名称、厂商名（中英文）搜索：

1. 输入关键词（如 `Claude`、`百度`、`longcat`），实时显示匹配列表
2. 点击搜索结果或按 Enter，图表自动：
   - 确保目标模型的厂商处于激活状态
   - 检查目标模型在当前坐标轴下是否有有效值
   - 如果没有（如免费模型 cost=0 在成本轴下不可见），自动切换到一组能显示该模型的坐标轴
   - 调整坐标轴范围确保模型在可视区域内
   - 在模型位置播放**灰色粒子十字光效**（2.5 秒动画），标注模型名称

### 底部排行榜

页面底部展示三张信息卡片：

| 卡片 | 排序依据 | 展示内容 |
|------|----------|----------|
| 💰 最佳性价比 Top 10 | 性价比 (IQ/$) 降序 | 模型名、IQ/$、成本、厂商 |
| 🏆 性能最强 Top 10 | 智能指数 (IQ) 降序 | 模型名、IQ、成本、厂商 |
| ⚡ 速度最快 Top 10 | 输出速度 降序 | 模型名、速度、成本、厂商 |

## 🏗️ 技术架构解读

### 整体结构

```
ai_kill_line_2026.html  （单文件，约 1895 行）
├── <head>
│   ├── Plotly.js CDN 引用
│   └── <style> 全部 CSS（暗色主题，约 210 行）
├── <body>
│   ├── 页面结构（标题栏、控制栏、厂商筛选、图表容器、信息面板、页脚）
│   └── <script> 全部 JavaScript（约 1600 行）
└── 核心逻辑模块
    ├── 数据层（内置数据 + 缓存 + 在线抓取）
    ├── 图表渲染层（updateChart + 布局 + 标签防重叠）
    ├── 搜索定位层（locateModel + doGlow 粒子动画）
    ├── 交互增强层（滚轮缩放、全屏、汉化工具栏）
    └── 信息面板层（排行榜）
```

### 数据层

```
初始化流程:
                                        ┌─────────────┐
                                        │  BUILTIN_DATA │  ← 内置 100+ 模型（硬编码 JSON）
                                        └──────┬──────┘
                                               │
                   ┌──────────────────────────────┐
                   │       initData() 函数         │
                   └──────────┬───────────────────┘
                              │
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
   ① 优先读缓存          ② 合并缓存+内置      ③ 无缓存用内置
   (localStorage)         (缓存版本旧时)       (首次打开)
          │                   │                   │
          └─────────┬─────────┘                   │
                    ▼                              │
              renderAll() 渲染页面  ◄──────────────┘
                    │
                    ▼
          ④ 后台异步 fetchLiveData()
             ├─ 成功 → 合并数据 + 存缓存 + 刷新
             └─ 失败 → 保持缓存/内置数据
```

**关键设计**：

- **三级数据源**：内置数据（硬编码）→ localStorage 缓存 → 在线抓取（Artificial Analysis 排行榜）
- **缓存版本控制**：通过 `CACHE_KEY = 'ai_kill_line_data_cache_v10'` 中的版本号 `v10` 管理缓存，修改版本号可强制所有用户刷新缓存
- **CORS 代理**：在线抓取使用多个 CORS 代理轮询，提高跨域请求成功率
- **HTML 解析**：`parseLeaderboardHTML()` 函数用三层策略解析远端排行榜 HTML（正则提取 `<tr>` → Markdown 表格 → 逐行管道符分割），避免灾难性回溯
- **合并策略**：在线数据与缓存数据按 `slug` 去重合并，在线数据仅补充新模型和更新已有模型的可变字段（IQ、价格、速度）

### 图表渲染层

**`updateChart()` 函数**（约 240 行）是核心渲染入口：

1. 读取用户选择的 X/Y 轴、IQ 过滤值、各项开关
2. 过滤数据：排除非正值（`<= 0`）、未激活厂商、低于 IQ 阈值的模型
3. 按厂商分组，为每个厂商创建一条 Plotly trace（散点 + 文本标签）
4. 计算标签位置（`calculateTextPositions`）：基于模型在图中的相对位置，用 8x8 网格碰撞检测，为每个标签选择冲突最小的 `textposition`
5. 如果开启帕累托前沿且 X=成本/Y=IQ，计算并添加前沿折线
6. 添加 AGI 参考线（shapes + annotations）
7. 调用 `Plotly.react()` 渲染
8. 渲染后汉化工具栏按钮提示

**标签防重叠算法**：
- 将图表区域划分为 8x8 网格
- 根据模型在图表中的归一化坐标 (nx, ny) 确定基础方向偏好（如左上角模型标签偏右下）
- 遍历已占用的网格区域，计算每个候选位置的冲突值
- 选择冲突最小的位置
- 辅以奇偶索引交替偏移，进一步分散标签

### 搜索定位层

**`locateModel(slug)` 函数**：

1. **厂商激活**：确保目标模型的厂商 chip 处于激活状态，若 chip 隐藏在"更多"按钮后则先展开
2. **IQ 过滤调整**：若当前 IQ 阈值高于模型 IQ，自动降低阈值
3. **坐标轴兼容检查**：
   - 检查模型在当前 X/Y 轴下是否有有效值（`> 0`）
   - 若无（如 `cost_per_task = 0` 的免费模型），按优先级尝试 6 种轴组合
   - 选中后自动切换 `<select>` 的值
4. 调用 `updateChart()` 刷新图表
5. 延时 200ms 后触发 `Plotly.relayout` 自适应缩放
6. 再延时 300ms 后调用 `doGlow()`

**`doGlow(slug, xVal, yVal)` 函数**（粒子动画）：

1. 在图表容器上覆盖一个 `<canvas>` 元素
2. 使用 Plotly 内部方法 `xaxis.d2p()` / `yaxis.d2p()` 将数据坐标转为像素坐标
3. 若模型不在当前坐标轴范围内，自动扩展范围
4. 启动 `requestAnimationFrame` 动画循环（2.5 秒）：
   - **0~60% 进度**：绘制从中心向外扩展的十字线 + 中心脉冲光点 + 持续生成粒子
   - **0~85% 进度**：绘制模型名称标签（圆角矩形背景 + 指向虚线）
   - **全程**：更新和绘制粒子（四个方向射出，灰色调，带阴影发光）
5. 动画结束后自动清理 canvas

### 交互增强层

- **鼠标滚轮缩放**：覆盖 Plotly 默认行为，以鼠标位置（而非图表中心）为缩放焦点。计算鼠标在 plot area 中的归一化坐标，映射到数据空间，然后以该数据点为中心缩放 0.8/1.25 倍。同时根据缩放级别动态调整标签字号
- **全屏**：通过 CSS class 切换 `position: fixed` + `100vh`，延时 100ms 后调用 `Plotly.Plots.resize()` 重绘
- **工具栏汉化**：渲染后 100ms 遍历 `.modebar` 中的 `[data-title]`，按映射表替换英文提示为中文

## 🎨 设计细节

### 视觉风格

- **暗色主题**：背景 `#0d0d0f`，卡片 `#161618`，与 Plotly 暗色图表无缝融合
- **标题渐变**：`linear-gradient(135deg, #667eea, #764ba2, #cc785c)` — 蓝紫到暖棕的渐变
- **厂商配色**：每个厂商有专属颜色（如 Anthropic `#cc785c`、OpenAI `#10a37f`），在圆点、厂商 chip、搜索结果中一致使用
- **中文厂商名**：`getDisplayName()` 函数为国内厂商添加中文前缀（如 百度、阿里巴巴、字节跳动、腾讯、智谱AI 等）

### 数据字段说明

每个模型对象包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 模型全名（英文） |
| `slug` | string | URL 友好的唯一标识（用于去重和搜索定位） |
| `intelligence_index` | float | 智能指数（Artificial Analysis 评分体系） |
| `cost_per_task` | float | 每任务成本（美元） |
| `input_price_per_m` | float | 输入价格 ($/1M tokens) |
| `output_price_per_m` | float | 输出价格 ($/1M tokens) |
| `speed` | float | 输出速度 (tokens/s) |
| `creator` | string | 厂商名 |
| `color` | string | 厂商代表色（hex） |
| `release_date` | string | 发布日期 (YYYY-MM-DD) |
| `deprecated` | bool | 是否已弃用 |
| `reasoning` | bool | 是否支持推理模式 |
| `value_ratio` | float | 性价比 = IQ / cost_per_task |
| `agi_level` | int | AGI 相对水平 (%) = (IQ - 20) / 20 * 100 |
| `short_name` | string | 简短名（超 30 字符截断） |
| `display_name` | string | 显示名（含中文厂商前缀） |

### 修改缓存版本

如需强制所有用户清空缓存重新抓取数据，修改 JS 中的版本号：

```javascript
const CACHE_KEY = 'ai_kill_line_data_cache_v10';  // v10 → v11
const CACHE_TIME_KEY = 'ai_kill_line_cache_time_v10';  // v10 → v11
```

页面加载时会自动清理旧版本缓存（通过遍历 `localStorage` 匹配 `ai_kill_line_data_cache_v` 前缀）。

## 📝 已知限制

1. **在线抓取不稳定**：CORS 代理可能被限流或不可用，但内置数据已足够丰富
2. **免费模型定位**：`cost = 0` 的模型在成本轴下不可见（被 `> 0` 过滤），搜索时会自动切换到速度/智能指数轴
3. **标签重叠**：在密集区域标签可能仍有部分重叠，算法已尽量减少但无法完全避免
4. **单文件体积**：内置 100+ 模型数据使 HTML 文件较大（约 100KB+），首次加载略慢
